How do I get a token?
  1. Open github.com → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Name it something like V8 stock admin and pick an expiry (up to a year).
  3. Set Resource owner to the account that owns the site.
  4. Under Repository access choose Only select repositories and pick the website repository.
  5. Under Permissions → Repository permissions, set Contents to Read and write. Nothing else is needed.
  6. Generate it, copy it and paste it above. Anyone with the token can edit the stock, so keep it private.
